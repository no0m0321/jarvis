FAQ

How does Jarvis know which language to use?

Priority: JARVIS_LANG env > ~/.jarvis/config.toml language key > system locale > English fallback. The install command pre-sets language in your config.toml.

Can I change language later?

Yes. jarvis lang ko sets to Korean, jarvis lang ja to Japanese, etc. Setting takes effect from the next jarvis ask/do call.

Are all languages equally fluent?

Korean and English have native system prompts (most natural responses). Other languages use the English persona base + a strong "always respond in X" directive — Claude handles the language perfectly, but the persona quirks may feel slightly Anglo-centric.

What about voice (TTS)?

On macOS, Jarvis automatically picks the best voice for your language (Yuna for Korean, Reed for English, Kyoko for Japanese, etc.). On Windows, it uses SAPI5 voices (Heami, David, Haruka, etc.).

What if my language isn't listed?

Open an issue on GitHub with your language code (ISO 639-1). Adding new languages is straightforward — just add an entry to i18n.LANGUAGES.
