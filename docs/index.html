Wake Word

VOICE · LOCAL · KO+EN

Tool-Use Agent

Claude가 296개의 client-side 도구를 자율 호출하는 multi-turn agentic loop. 셸 · 파일 · 캘린더 · 브라우저까지.

AGENTIC · MULTI-TURN

Holographic HUD

80-particle 3D cloud, voice-reactive scaling, hexagonal grid, code rain. Übersicht widget으로 데스크톱에 상주.

HUD · v6 · 30+ FX

Persistent Memory

~/.jarvis/memory.md 자동 첨부 + chromadb 벡터 메모리. 사용자 선호와 맥락을 영구 학습.

VECTOR · ∞ MEMORY

Multi-Persona

jarvis · casual · formal · creative — 4종 system prompt 즉시 전환. JARVIS_PERSONA env 또는 CLI flag.

4 · PERSONAS

launchd Daemon

RunAtLoad + KeepAlive로 macOS 부팅 시 자동 시작. health server :41417로 /healthz · /metrics 노출.

AUTO-START · HEALTHCHECK

Multi-Provider

Anthropic 기본 · OpenAI · 로컬 Ollama 즉시 전환. JARVIS_PROVIDER env 한 줄로 LLM 백엔드 변경.

CLAUDE · OPENAI · OLLAMA

Plugin System

~/.jarvis/plugins/*.py 자동 import. GitHub repo URL 한 줄로 plugin 설치. 도구를 무한 확장.

한 줄로 시작

설치 → init wizard → "자비스 부르기" 까지 5분.
모든 명령은 셸과 음성에서 동일하게 동작합니다.

  • jarvis init# API 키 / 호칭 / 메모 템플릿
  • jarvis doctor# 진단 (마이크 / launchd / HUD)
  • jarvis ask# 단발 질의
  • jarvis chat# 대화형 모드
  • jarvis do# 자율 실행
  • jarvis listen# 음성 한 번 듣기
  • jarvis daemon install# 부팅 시 자동 시작
  • jarvis hud start# 홀로그래픽 HUD 활성화
